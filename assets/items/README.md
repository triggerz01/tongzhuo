# 桌面摆件素材规格

现在这五个（`lamp/plant/mug/books/cat`）是**占位图**，我随手画的 SVG，
风格是扁平的，和照片背景不搭。真素材来了直接替换同名文件即可，
`catalog.json` 里的路径不用动。

## 一句话结论：要 **2D**，不要 3D

桌子本身就是一张 2D 图 —— 场景照片底部那条桌面放大后贴在 `#fg` 上。
3D 摆件放不进来：三维场景整个在 canvas 里，而 canvas 在桌面图**底下**，
摆上去会被桌面盖住。就算硬渲染到上层，也要拿一个三维物体去跟一张
照片对透视、对光线、对颗粒感，那是费力不讨好的事。

（你可以用 Blender / C4D **渲染**出图，但交给我的是渲染结果的 PNG。）

## 文件格式

| 项 | 要求 |
|---|---|
| 格式 | **PNG，带 alpha 透明通道**（32 位）。SVG 也收 |
| 画布 | **512 × 512**；特别大的东西（比如猫、显示器）可以 1024 × 1024 |
| 背景 | **必须透明**。不要白底，不要棋盘格底 |
| 命名 | 英文小写，和 `catalog.json` 里的 `asset` 对上 |

## 构图（这条最重要）

**物体的底边贴着画布底边，水平居中。**

```
┌─────────────────┐  ← 画布顶
│                 │
│      ╭───╮      │  上方留白，多少都行
│      │   │      │
│     ─┴───┴─     │
└─────────────────┘  ← 物体和桌面接触的那条线，必须压在画布底边
        ↑
     水平居中
```

程序把「画布底边中点」当作物体和桌面的接触点。这样换一排格子时
只需要改缩放，不用重新对位。如果物体浮在画布中间，摆上桌会飘起来。

左右各留 5% 左右的空隙，别顶死边。

## 视角和光线

- **视角**：坐着的人平视略俯，俯角大约 **15°** —— 主要看到侧面，
  只看到一点点顶面。和现在四张背景照片是同一个视角。
  不要正俯视（会像贴纸），也不要仰视。
- **光线**：**中性、柔和、主光在右上方**。
  背景是可以换的（自习室 / 图书馆 / 咖啡馆 / 卧室），所以**不要把
  强烈的有色光烘进去** —— 我们在代码里按场景统一调色温和投影。
- **投影**：可以不画。我们用 CSS 的 `drop-shadow` 统一加。
  真要画就画极淡的接触阴影（物体正下方一小片），别画长投影。

## 风格

背景是**写实照片**，人物是二次元。摆件是物理上放在照片桌面上的东西，
所以**跟着照片走：写实或半写实渲染**。扁平矢量放上去会很跳
（现在这五个占位图就是反面教材）。

## 尺寸怎么定

不在图里定，在 `assets/catalog.json` 里用 `deskWidth` 定 ——
它是这件东西在最近一排时占**画面宽度**的百分比。现在的值：

| 物件 | deskWidth |
|---|---|
| 马克杯 | 7 |
| 小绿植 | 9 |
| 暖光台灯 | 11 |
| 一摞书 | 12 |
| 趴着的猫 | 15 |

所以你画的时候不用管相对大小，把物体画满画布宽度就行，
比例我在 JSON 里调。

## 加一件新东西

1. 图丢进 `assets/items/`
2. 在 `assets/catalog.json` 里加一条：

```json
{
  "id": "item_headphone",
  "name": "耳机",
  "type": "item",
  "price": 90,
  "description": "戴不戴都行，放着就挺好。",
  "preview": "assets/items/headphone.png",
  "asset": "assets/items/headphone.png",
  "deskWidth": 10,
  "available": true
}
```

`preview` 是商店卡片上的图，`asset` 是摆在桌上的图 —— 通常同一张。
`id` 一旦发出去就别改，用户的已购记录是按 id 存的。

## AI 生成的话

提示词大概是这个方向：

> 一盏暖色木质台灯的产品渲染图，纯透明背景，视角为坐姿平视略俯（约15°），
> 柔和中性布光主光来自右上，写实风格，物体底部位于画面底边中央，
> 不要投影，不要背景

生成完如果是白底，用抠图工具去掉白底再存成 PNG。
