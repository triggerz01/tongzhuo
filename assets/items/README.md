# 桌面摆件素材规格

现在这五个是**占位图**，扁平 SVG，和照片背景不搭。
真素材替换同名文件即可， 里的路径不用动。

**完整的 AI 工具推荐和渲染词见 [](../../docs/摆件素材怎么做.md)。**
这里只留技术约定。

## 一句话结论：要 2D，不要 3D

桌子本身就是一张 2D 图 —— 场景照片底部那条桌面放大后贴在  上。
3D 摆件放不进来：三维场景整个在 canvas 里，而 canvas 在桌面图**底下**，
摆上去会被盖住。就算硬渲染到上层，也要拿三维物体去跟一张照片对透视、
对光线、对颗粒感，费力不讨好。

（可以用 Blender 之类**渲染**，但交给程序的是渲染结果的 PNG。）

## 三条硬约定

**1. 透明底。** PNG 带 alpha 通道，不要白底，边缘不要留白圈。

**2. 物体底边贴着画布底边，水平居中。**



程序把「画布底边中点」当接触点。物体浮在画布中间的话，摆上桌会飘起来。

**3. 画布比例决定它在桌上多大。** 图片是在「占位框」里
 贴底缩放的，框的大小由  的
 定。

| cells | 建议画布比例 | 例如 | 用于 |
|---|---|---|---|
| 1×1 | 约 1:1 | 512×512 | 马克杯、笔筒、闹钟 |
| 1×2 | 约 2:3 | 512×768 | 绿植、保温杯 |
| 1×3 | 约 1:3 | 360×1024 | 台灯 |
| 2×1 | 约 9:4 | 900×400 | 一摞书、笔袋 |
| 2×2 | 约 3:2 | 900×620 | 猫、小音箱 |

最长边 1024 就够 —— 桌面带只占屏幕 28%，再大是浪费。

## 视角和光线

- **视角**：坐着的人平视略俯，俯角约 **15°**，和四张背景照片一致。
  主要看侧面，只看到一点顶面。不要正俯视（像贴纸），不要仰视。
- **光线**：中性柔和，主光右上。**不要把有色强光烘进去** ——
  背景可换（自习室 / 图书馆 / 咖啡馆 / 卧室），我们在代码里统一调。
- **投影**：不用画，CSS 统一加 。要画就画极淡的接触阴影。

## 风格

背景是写实照片，摆件物理上放在照片桌面上，所以**跟着照片走：
写实或半写实渲染**。扁平矢量放上去很跳（现在这五个就是反面教材）。
