# 场景背景图放这里

把图片丢进这个目录就会被自动识别，**不用改代码、不用改文件名**。
点自习室窗口右下角的「切换场景」循环切换；文件名会作为场景名显示。

建议命名（决定切换顺序）：

```
01-自习室夜.jpg
02-图书馆.jpg
03-咖啡厅.jpg
04-卧室夜.jpg
```

---

## 规格

| 项 | 要求 |
|---|---|
| 格式 | **JPG** 或 **WebP**（不要 PNG，背景不需要透明，PNG 白白大 3–5 倍） |
| 分辨率 | **2560×1440**，最低 1920×1080 |
| 比例 | **16:9**（窗口用 `cover` 裁切，比例差太多会裁掉重要内容） |
| 体积 | 单张 ≤ 800KB（质量 80 的 JPG 足够，背景本来就要虚化） |

## 画面内容的三条硬要求

这三条决定了角色是"在场景里"还是"贴在背景上"：

1. **视角必须是坐在桌前平视** —— 相机高度约 1.1–1.3 米（坐姿眼高），水平看向前方。
   俯视、仰视、广角全景都会让角色像贴纸。

2. **画面中央要留空** —— 角色站在正中间偏下的位置。中央别放柜子、柱子、显眼的人或字。

3. **光源方向：主光在右侧偏暖**（台灯感），左侧可以有冷色补光（窗外月光）。
   这样才能和 3D 角色的打光对上。如果你给的图光在左边，告诉我，我把 3D 灯光翻过来就行。

另外：**画面里不要有人**。

## 我这边做了什么配合

背景图不是直接铺上去的，加了三层合成处理，让 2D 背景和 3D 角色像在同一个空间：

- **虚化**（默认 3px）—— 制造景深，把角色和背景分开，这一步对"融合感"贡献最大
- **压暗降饱和**（0.82 / 0.92）—— 背景不能比角色亮，否则抢戏
- **色调统一层** —— 一层半透明冷色盖住整个背景，统一色温

这三个参数可以实时调。调好了告诉我数值，我固化进代码。
