# 语音台词表

> 这份表是录音/合成的唯一依据。改台词就改这里，然后同步 `renderer/lines.js`。

## 人设定调

主张是「**它不会来查你。它只是一直在。**」——所以她不是教导主任，是同龄人。

写台词的四条硬规矩：

1. **短。** 8~14 个字。超过 20 字念出来就拖沓，情绪也散了。
2. **不说教。** 不许出现「你应该」「要专注」「加油」「努力」「不能玩手机」。
3. **克制胜过激烈。** 玩手机那条只说「手机。」比骂一句管用得多 —— 被人看见比被人骂更让人放下手机。
4. **不指挥。** 她陈述自己的感受（我一个人坐着呢），不下达指令（快回来）。

## 二、摄像头联动（核心）

### 专注够久 → 夸你 `praise`

开心 + 少女可爱动作（点赞）

- 你已经坐了很久了，厉害啊。 *(现有)*
- 一直没抬头，我都看着呢。
- 这一段很稳。
- 挺好的，就这样。
- 你今天状态不错。
- 我都不好意思打扰你。

### 玩手机过久 → 失望 `disappoint`

生气失望 + 皱眉叉腰

- 手机。 *(现有，最好的一条，别改)*
- ……我看见了。
- 就看一眼？
- 它比我好看是吧。 ← 吃醋，不说教
- 放下吧。
- 我等你。 ← 最克制的一条

### 离席过久 → 难过 `lonely`

难过

- 你去哪儿了，我一个人坐着呢。 *(现有)*
- 人呢。
- 桌子空了。
- 我还在这儿。
- （一声叹气，无词） ← 纯气声，不合成，真人录

### 离席后回来 → 欢迎 `welcome`

开心

- 你回来啦，我等你半天了。 *(现有)*
- 回来了。
- 我就知道你会回来。
- 位置我给你留着呢。

### 犯困 `sleepy`

打哈欠 + 困倦表情

- **默认不说话**，只有哈欠声。现在就是这样，是对的。
- ……困了？ ← 低频率使用
- 要不趴一会儿。

### 遮挡镜头 `puzzled`

疑惑

- ？ *(现有)*
- 我看不见你了。
- 挡住了。

### 背对镜头 `backturn` —— **目前没有反应，缺**

感知层能认出这个状态（`classifier.py` 有 `backturn`），但 `REACTIONS` 里没有对应项。
和「离席」不一样：人还在，只是转过去了。语气该是好奇，不是难过。

- 你转过去干嘛呢。
- 背对着我啦？
- 我在你后面看着呢。 ← 半开玩笑

### 待机小插曲

现在是「只做表情和小动作，不说话」，**这个默认是对的**，别改成句句有声。
最多加一句极短的气音垫场：

- 嗯……

## 三、不配语音的（只留字幕）

这几类要么是动态字符串（预录不了），要么念出来很吵：

- 标定：`保持你平时看书的姿势，15 秒…` / `记住你的姿势了。` / `标定失败：…`
- 摄像头出错：`摄像头出错：<message>`
- 切换场景：`（自习室（夜））`

## 四、实现要解决的三件事

### 1. 一句话不能用一整场

现在每个触发只有**一句固定台词**。测试阈值下 `praise` 每分钟触发一次 ——
一场 45 分钟的自习会把「你已经坐了很久了，厉害啊」重复十几遍，非常出戏。

必须做**多候选 + 不重复随机**：同一触发的台词池里随机抽，抽过的进冷却，
池子走完才允许重复。

### 2. 预录 还是 实时 TTS

**建议预录。** 理由：

- 断网也能演示 —— 现场网络是最不可控的一环
- 零延迟，情绪和口型对得上
- 音色可控，不会某一句突然跑调

代价是**台词必须冻结**。这份表定稿之后就不能随口改了。

### 3. 口型要用音频时长驱动

现在 `talkAtLeast(hold * 0.7)` 是拍脑袋估的。接上音频之后应该用
`audio.duration` 驱动嘴的开合，否则会出现「声音停了嘴还在动」。
