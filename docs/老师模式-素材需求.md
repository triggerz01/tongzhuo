# 老师监督模式 —— 需要你准备的素材

识别逻辑完全复用同学陪伴模式，不用改。差别只在**表现层**：
站着、全身、教室、语气更硬。

---

## 一、背景图：一张就够

`assets/scenes/` 里再放一张，命名 `05-教室.jpg`。

### 硬指标

| 项 | 要求 |
|---|---|
| 尺寸 | **1920 × 1080**（和现有四张一致，程序按这个比例裁） |
| 视角 | **坐在学生座位上平视讲台**，相机高度约 1.1~1.2 米，**接近水平，不要俯视也不要仰视** |
| 画面里不能有人 | 一个人都不要，老师是 3D 模型叠上去的 |

### 构图（这条最关键）

**老师站的那条地面线，要落在画面纵向 80%~88% 之间。**

```
┌────────────────────────────┐  0%
│                            │
│        黑板 / 白板          │
│                            │
│   ←—— 这一片留空，老师站这儿  │
│                            │
├────────────────────────────┤  ~82%  ← 讲台地面线
│        讲台侧面 / 地面       │
└────────────────────────────┘  100%
```

- **画面正中偏下那一块必须是空的** —— 讲桌、投影幕、盆栽都别摆在正中，
  否则会和老师重叠
- 讲桌可以有，但**推到左边或右边三分之一处**
- 地面线要看得出来（讲台边缘、地砖分界、踢脚线都行），
  我按这条线把老师的脚放上去

如果你生成出来这条线不在 80~88%，也不用重做 —— 告诉我实际位置，
我在代码里调参数对上就行。**别为了凑数字牺牲画面。**

### 内容和光线

- 黑板或白板（可以有写了一半的板书），讲台，教室前部
- 中景可以有几排空课桌，虚化
- 光线：**均匀的日光或教室顶灯，中性色温**。
  不要强烈的暖色或冷色 —— 角色是二次元着色，背景太偏色会打架
- 和现有四张一样带一点景深虚化，程序还会再叠一层轻微模糊

### 提示词（给即梦）

> 空无一人的中学教室前部，从学生座位平视讲台的视角，相机高度约1.2米水平拍摄，
> 画面中有黑板和讲台，讲桌靠画面右侧，讲台正中区域留空，
> 中景是几排虚化的空课桌，自然均匀的日光照明，中性色温，写实摄影风格，
> 浅景深，16:9横构图，画面里没有任何人

## 二、动作：现有的能用一半

### 好消息：现在这批里有 8 个本来就是站姿

`Angry`、`Bored`、`Breathing-Idle`、`Clapping`、`Head-Nod-Yes`、
`Look-Around`、`Sad-Idle`、`Waving` —— 这些从 Mixamo 下下来就是站着的，
之前在陪伴模式里靠前景桌子挡住腿才没穿帮。**老师模式直接就能用。**

用不了的只有三个：`Sitting-Idle`、`Sitting-Thumbs-Up`、`X Bot@Writing`。

### 需要你补的（按重要性排）

Mixamo 的名字时有出入，我给**描述 + 英文搜索关键词**，按描述挑就行。
下载设置和之前一样：**FBX Binary / Without Skin / 30 fps**。

| # | 要什么 | 用在哪 | 搜索关键词 |
|---|---|---|---|
| 1 | **双手抱胸或背手的站立待机** | 底层循环，全程都在放 | `idle`, `standing idle`, `crossed arms` |
| 2 | **竖大拇指（站姿）** | 专注够久 → 夸你 | `thumbs up` |
| 3 | **指着你 / 手指点两下** | 玩手机 → 批评 | `pointing`, `angry point` |
| 4 | **摇头（否定）** | 玩手机 / 失望 | `shaking head no`, `annoyed head shake` |
| 5 | **看表 / 不耐烦地等** | 离席过久 | `checking watch`, `impatient`, `waiting` |
| 6 | **叉腰 / 双手扶讲台** | 严肃待机的第二种 | `hands on hips`, `standing` |

**1 是最重要的一个** —— 底层循环占了整场 90% 的时间。
现在的 `Breathing-Idle` 是双手自然下垂，看着像在发呆；
抱胸或背手才有"监考"那个味道。

**2~6 各一个就够，不用找很多。** 找不到的跳过，我用现有的顶上：
- 没有竖大拇指 → 用 `Clapping`
- 没有指人 → 用 `Angry`
- 没有看表 → 用 `Bored`

### 一个技术限制，先说清楚

**踱步 / 走动的动作用不了。** 我们的动作加载器**刻意丢掉了 hips 的位移轨道**
（`renderer/mixamo.js` 里有注释：坐姿和站姿的根高度不一样，保留位移会让人物
上下乱跳）。所以走路动作会变成原地滑步，很难看。

想要"老师在讲台上走来走去"的巡视感，得我改加载器在老师模式下保留位移 ——
这件事要做也能做，但不在这一轮。先做站着不动的版本。

## 三、台词：我按你给的风格写好了

没有录音，先只出字幕（`voice.js` 里没有音频包的角色会自动退化成只显示字幕，
不报错）。以后录了丢进 `assets/voice/teacher/` 就自动接上。

| 场合 | 同学陪伴 | 老师监督 |
|---|---|---|
| 开场 | 开始了，我也开始。 | 坐好，开始吧。 |
| 专注够久 | 你已经坐了很久了，厉害啊。 | 不错，很专注。 |
| 玩手机 | 手机。 | 又在玩手机了，你是怎么跟我保证的。 |
| 离席过久 | 你去哪儿了，我一个人坐着呢。 | 怎么走了这么久，这就坚持不下去了？ |
| 离席后回来 | 你回来啦，我等你半天了。 | 你回来了，收拾好心情赶紧专注学习。 |
| 收工 | 时间到了，今天到这儿。 | 时间到，今天就到这里。 |

完整的一份在 `renderer/voice.js` 的 `LINES_TEACHER` 里。

## 四、这一轮我不做的

- **老师模式下没有桌子和摆件**（你定的）。前景桌面层和摆件层在这个模式下关掉
- **抓拍照样有** —— 批评玩手机时一样抓拍，存进当天记录
- **点数规则不变** —— 夸奖 +20 / 玩手机 −5 / 离席 −5 / 完整完成 +100
