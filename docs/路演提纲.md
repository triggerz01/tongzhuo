## 零、一句话（先把这句写好，其余都围着它转）

> **市面上的自习监督软件都在替你抓自己的错。我们做的是一个坐在对面的人。**

备选：

- 「它不会来查你。它只是一直在。」（这是产品里真正印在主界面上的那句）
- 「专注这件事，不是被盯出来的，是被陪出来的。」

**这句话必须在开场 20 秒内出现，并且在结尾再出现一次。**

## 一、问题（60 秒）

### 别从"大学生拖延严重"开始

那是所有人都会讲的开头，评委已经听了一天。**从一个具体的反面开始。**

建议的切入：

1. 现在的自习监督类产品是怎么工作的 —— 摄像头对着你，你一玩手机它就
   截图、扣分、发到群里、生成"罪证"。（可以点名说这一类，不必点具体产品名）
2. 这类产品**有效，但代价是让人更焦虑**。它把学习变成一场自证清白。
3. 一个反问：**你上一次能安静坐两个小时，是因为有人盯着你，
   还是因为旁边有个人也在写？**

> 这个反问是整个稿子的支点。图书馆效应是真实的、每个人都体验过的 ——
> 我们做的就是把它搬回宿舍。

### 一句话收束

> 「Build with Care」这个题目，我们理解成：**关怀不是监视的温柔版本，
> 是另一件事。**

---

## 二、我们的主张（40 秒）

三条，讲清楚就够：

1. **她不评判，她只是在场。**
   角色全程在你对面自习。你专注，她抬头看你一眼；你走神，她的反应是
   失落，不是训斥。
2. **克制比激烈有用。**
   举一个具体例子（**这是全场最好的一个细节，一定要讲**）：
   > 检测到玩手机时，她只说两个字 —— **「手机。」**
   >
   > 我们试过写成"别玩手机了，专注一点"，但**被看见比被训斥更让人放下手机**。
3. **关怀不止一种形状。**
   有人需要陪伴，有人需要压力。所以我们做了两种模式：
   **同学陪伴** 和 **老师监督**。同一套识别，不同的语气和姿态。

## 三、现场演示（120~150 秒，全场重心）

**建议：先放 60 秒录屏，再切实机。** 理由见第八节。

### 动线（按这个顺序，别跳）

| # | 动作 | 要说的话 |
|---|---|---|
| 1 | 主界面 | 「伴你同行」，底下那句「它不会来查你。它只是一直在。」念出来 |
| 2 | 设置 → 选同桌 | 男生/女生，红板对切转场。一句带过：「谁陪你，你自己定」 |
| 3 | 布置桌面 | 像种植物一样把台灯、绿植、猫摆到桌上。**这里可以停两秒让评委笑一下** |
| 4 | 准备一下 → 校准位置 | 按轮廓线对好坐姿。**顺势讲隐私**（见第五节） |
| 5 | 进入自习室 | 她坐在对面，桌上是你摆的东西。**停三秒不说话，让画面自己讲** |
| 6 | **拿起手机** | 她皱眉、叉腰，说「手机。」 —— 同时右上角点数 −5，**画面被抓拍** |
| 7 | 放下手机继续写 | 过一会儿她笑，点赞，「不错，很专注」，点数 +20 |
| 8 | 结束这一场 | 结算页：数字滚动 → 柱子生长 → 明细逐行落 |
| 9 | 学习记录 | 日历 → 点开那一场 → **事件时间线 + 当时的抓拍** |
| 10 | 切老师模式 | 同样玩手机，她站在讲台上说「又在玩手机了，你是怎么跟我保证的。」 |

### 演示时的三个提醒

- **第 6 步是全场的高潮**，前面所有铺垫都是为了它。语音会真的响 ——
  提前确认场地音量。
- 第 9 步的抓拍是"隐私"和"有用"的交汇点，**必须紧接着说七天自动删**。
- 阈值是**压缩过的**（手机 15 秒触发，真实产品是 1 分钟）。
  **主动说明**，别等评委发现。说法：
  > 「为了在两分钟里演完，我把触发时间压缩了。真实使用是玩手机满一分钟她才开口 ——
  > 我们不想做一个你一低头它就叫的东西。」

## 四、技术怎么支撑这个主张（60 秒）

**不要报菜名。** 每一项技术都要接一句"所以"。

| 技术 | 所以 |
|---|---|
| MediaPipe 本机推理，识别 6 种状态<br>（专注 / 离席 / 背对 / 玩手机 / 犯困 / 遮挡） | 所以她知道你在干什么，**不用把画面传出去** |
| **时序判定，不是单帧判定** —— 所有判断都建立在"持续多久"上 | 所以你低头捡支笔，她不会跳出来 |
| 开场前做一次 15 秒基线标定 | 所以判断的是**你**走神了，不是"和标准姿势不一样" |
| VRM + Mixamo，57~72 个细分表情 morph | 所以喜怒哀乐是真的分得开，不是换贴图 |
| **字幕和音频同源，口型按音频真实时长驱动** | 所以嘴不会在声音停了之后还在动 —— 这一条最难，也最决定"她在那儿"成不成立 |
| 前景桌面遮挡 + 摆件按格子透视缩放 | 所以你和她像在共用一张桌子，而不是她贴在背景上 |

### 如果评委追问"技术含量"

- 三档帧率（采集 15 / 人脸 5 / 手机 3 FPS）—— 为了在普通笔记本上跑得动
- 手机检测有 2.5 秒滞回，防止晃一下就丢
- 判定优先级里，**"检出手机"必须排在"没检出人脸"之前** ——
  低头看手机时人脸会丢失，顺序错了就永远触发不了。这个 bug 我们踩过
- 动作交叉淡入时要显式复位底层循环权重，否则绑定姿势（T-pose）会从缝里漏出来

> 这几条讲一条就够，**目的是证明我们真的把它跑起来过**，不是拼了个 demo。

## 五、隐私（30 秒，但分量很重）

**主动讲，别等问。** 这是摄像头类产品的第一质疑点。

四句话：

1. **所有识别都在本机完成**，没有任何一帧画面上传。
2. **画面不落盘。** 内存里推理完就丢。
3. **摄像头默认关闭**，要你自己点开；结束自习就真正释放（不是软暂停）。
4. **唯一会存下来的是玩手机时的抓拍** —— 刻意压到 280 像素、很糊，
   只存在你自己的电脑上，**七天自动删除**。

> 建议加一句立场：
> 「我们不做'把证据发到家长群'那种功能。留这张图是为了让你自己第二天看一眼，
> 不是为了让别人看。」

## 六、诚实清单（20 秒，别跳过）

**主动说没做完的，比被问出来强得多。** 评委对"知道自己边界"的团队评价更高。

**已经跑通的：**
- 完整闭环：主界面 → 设置 → 准备 → 校准 → 自习 → 结算 → 日历 / 商店
- 摄像头识别 6 种状态并联动表情、动作、语音、点数、抓拍
- 37 条真人配音（34 句台词 + 3 段无字气音），女生
- 学习记录日历、单场详情、月度总结
- 专注星点数、商店四分类、桌面自定义
- 13 个单元测试，`npm test` 可跑

**还没做完的（照直说）：**
- **老师监督模式还在做** —— 识别逻辑已经复用好了，教室背景和站姿动作在补
- 男生和老师**还没有配音**，目前只出字幕
- 基线标定还没在多个人身上长期验证
- 商店里的东西**还没接上真正的解锁**，现在买了只是记账

## 九、Q&A 预案

| 可能的提问 | 怎么答 |
|---|---|
| **这和番茄钟 / Forest 有什么区别？** | 番茄钟管的是时间，我们管的是**那段时间里你在不在**。而且它们不会在你回来时说"位置我给你留着呢" |
| **真的能提高专注吗？有数据吗？** | **别编数据。**照实说：现在没有。我们做的是把图书馆效应搬回宿舍，这个效应本身是被广泛体验过的，但我们的产品还没有做过对照实验。下一步就是找 20 个人用两周 |
| **摄像头会不会侵犯隐私？** | 见第五节四句话。补一句：本机推理、七天自动删、默认关闭，这三条是**设计时就定下的**，不是后来补的 |
| **为什么要 3D 人物？2D 立绘不行吗？** | 因为要"在场"。2D 立绘换的是图片，3D 才有微表情、呼吸、看你一眼、低头写字这些**没有信息量但有存在感**的动作 |
| **你们两个人怎么分的工？** | 见第十节 |
| **商业化 / 怎么赚钱？** | 商店已经是雏形：人物、场景、桌面摆件。但**先别急着讲变现** —— 这是关怀赛道，讲多了容易跑偏。一句带过 |
| **老师模式会不会又变成监视？** | 好问题，要正面接：**是用户自己选的**。区别在于「被选择的严厉」和「被强加的监视」。而且老师模式一样不上传、一样七天删 |
