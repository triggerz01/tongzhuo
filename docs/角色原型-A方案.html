看这三件事

① 它从不完全静止——呼吸 4.2 秒一轮，眨眼随机且成簇。② 行为间隔不是固定周期，"演示节奏" 5–13 秒，"真实节奏" 40–110 秒。③ 每个动作都有前摇和收尾（0.5 秒缓动），没有瞬切。

为什么捏脸是白赚的

五官是独立图层，所以眨眼 = 把眼睛的 ry 改成 1.2，打哈欠 = 换一条嘴巴路径，发呆 = 眼睛压扁 55%。捏脸系统和表情动画是同一套资产，做了前者等于顺手做完后者。

整个角色 0 张图片

全部是 SVG 图形，文件几十 KB，换色、换服装、换体型都是改参数。没有版权问题、没有一致性漂移、没有恐怖谷。缺点也说清楚：它是"清爽"，不是"精美"。
